# star_classifying

CS4641 ML project: classifying stars with **Gaia DR3**.

- **Phase 1 (supervised):** predict a star's spectral type (`spectraltype_esphs`:
  O, B, A, F, G, K, M, CSTAR) from photometry / colors.
- **Phase 2 (unsupervised):** cluster the HR diagram using temperature and
  luminosity, then compare the clusters against the spectral types.

See [PROJECT_GOAL.md](PROJECT_GOAL.md) for the full description.

Data is pulled directly from the Gaia Archive via `astroquery` -- no manual
download needed.

## Setup

```bash
python -m venv .venv
# Windows PowerShell:
.\.venv\Scripts\Activate.ps1
# macOS/Linux:
# source .venv/bin/activate

pip install -r requirements.txt
```

## Running Phase 1

```bash
python src/fetch_data.py     # queries Gaia, caches to data/ (~3 min)
python src/preprocess.py     # cleaning + EDA plots -> figures/
python src/supervised.py     # trains classifiers, writes metrics + figures/
```

## Running Phase 2

```bash
python src/unsupervised.py   # HR clustering + comparison -> figures/
```

Run this after `preprocess.py`. It reads `data/gaia_dr3_clean.parquet`
and does not query the Gaia archive.

Open the single-window Python testing viewer with:

```bash
python testing.py
```

It shows the full-data HR scatter, a density view, and saved diagnostics.
The GMM uses fixed k=8 and KMeans uses k=2. The first run fits and caches
these results; later runs reuse them. Use Matplotlib's toolbar to zoom,
pan, reset, and save. `python testing.py --save` renders all four views
without opening a window. The original k-search view remains labeled as
the original search, which selected GMM k=10.

The `data/` and `figures/` folders are git-ignored because they are
regenerated by the scripts above.

The unsupervised run also saves `kmeans_selection.csv`, `gmm_selection.csv`,
and `ari_summary.csv` in `figures/`. Nonconverged GMM fits are excluded from
selection, and an upper-boundary BIC choice is explicitly flagged.

Run the clustering regression checks with:

```bash
python -m unittest discover -s tests -v
```
